# Контракт даних та специфікація API (Data Contract) – Проєкт «PythonStart»

## 1. Призначення документа
Цей документ визначає єдиний формат обміну даними у форматі **JSON** між мережевим модулем `js/api.js` та модулем відображення інтерфейсу `js/apiWidget.js` у межах Лабораторної роботи № 9.

## 2. Джерела даних (Endpoints)
1. **Основне джерело навчальних порад (JSON API через HTTP GET):**
   * Локальний/серверний шлях: `./data/daily-tips.json` (на GitHub Pages роздається як статичний REST JSON-ендпоінт).
2. **Зовнішній публічний REST API (жива статистика офіційного репозиторію мови Python):**
   * URL-адреса: `https://api.github.com/repos/python/cpython`
   * Метод запиту: `GET`
   * Авторизація: не потрібна (відкритий публічний ендпоінт, без API-ключів у клієнтському коді).

## 3. Структура об'єкта «Порада дня з Python» (Tip Object)
Кожен елемент масиву `tips` у відповіді має містити такі обов'язкові поля:

| Назва поля | Тип даних | Обов'язковість | Опис призначення |
| :--- | :--- | :--- | :--- |
| `id` | `string` | Так | Унікальний ідентифікатор поради (наприклад, `"tip-fstrings"`) |
| `category` | `string` | Так | Тематична рубрика (`"Лайфхак Python"`, `"Чистий код"`, `"Налагодження"`) |
| `title` | `string` | Так | Короткий заголовок поради для картки |
| `explanation` | `string` | Так | Зрозуміле пояснення правила для учня 8–9 класу |
| `codeSnippet` | `string` | Так | Короткий приклад коду мовою Python |

## 4. Структура нормалізованої відповіді модуля `js/api.js`
Функція `loadPythonTipData()` завжди повертає об'єкт єдиного формату (незалежно від того, чи спрацював основний запит, чи резервний Fallback):
- `ok` (`boolean`): `true` – дані отримано з мережі, `false` – використано резервні дані після помилки;
- `sourceLabel` (`string`): текст бейджа джерела (`"Дані завантажено з API"` або `"Автономний резерв (Fallback)"`);
- `tips` (`Array<Object>`): масив об'єктів порад;
- `repoStats` (`Object | null`): `{ stars, openIssues, language, htmlUrl }` – жива статистика з GitHub REST API;
- `errorMessage` (`string | null`): текст технічної помилки (якщо трапився збій).
