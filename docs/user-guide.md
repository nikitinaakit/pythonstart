# Інструкція користувача навчального тренажера «PythonStart»
*(Посібник для учнів 8–9 класів та вчителів інформатики ЗЗСО)*

## 1. Призначення тренажера та початок роботи
**«PythonStart»** – це безкоштовний інтерактивний вебтренажер, який допоможе вам опанувати перші теми програмування мовою Python без необхідності встановлювати складні програми на свій комп’ютер чи смартфон.

### Як відкрити тренажер:
1. Відкрийте будь-який сучасний веббраузер (Google Chrome, Mozilla Firefox, Microsoft Edge або Safari).
2. Перейдіть за публічним посиланням, яке надав учитель:
   `https://nikitinaakit.github.io/pythonstart/`
3. Сайт завантажиться миттєво і відразу готовий до роботи!

## 2. Огляд інтерфейсу користувача
Екран тренажера поділено на чотири зручні зони:
- **Верхня панель (Шапка сайту):** містить назву тренажера, ваш поточний лічильник успішності (наприклад, `Мій прогрес: 2 / 4 (20 балів)`) та кнопку **«↺ Скинути»** для очищення результатів перед новою спробою.
- **Ліва бічна панель («Каталог тем»):** містить поле швидкого пошуку за ключовими словами, кнопки фільтрації (**«Усі»**, **«Опрацьовані»**, **«Неопрацьовані»**) та картки чотирьох навчальних тем курсу Python.
- **Центральна робоча область («Інтерактивний урок»):** тут відображається назва активної теми, рівень складності, короткий теоретичний конспект, зразок коду Python та блок практичного завдання з полем для введення відповіді.
- **Інформаційний блок «Порада дня з Python»:** показує корисні практичні лайфхаки з оформлення коду за стандартом PEP 8 та живу статистику проєкту.

## 3. Покроковий алгоритм роботи учня з уроком
1. **Оберіть тему:** у лівій панелі натисніть на картку потрібної теми (наприклад, *«1. Змінні та типи даних»*). Активна картка підсвітиться синьою рамкою.
2. **Опрацюйте теорію та приклад:** уважно прочитайте теоретичну довідку в центральній частині екрана та розберіть готовий приклад коду у темному блоці.
3. **Виконайте практичне завдання:** прочитайте умову вправи під заголовком *«Практичне завдання»* та введіть свою відповідь у текстове поле.
4. **Скористайтеся підказкою (за потреби):** якщо ви сумніваєтеся у відповіді, натисніть кнопку **«Показати підказку»** – під формою з’явиться жовтий блок із навідним поясненням.
5. **Перевірте результат:** натисніть синю кнопку **«Перевірити відповідь»** (або клавішу `Enter` на клавіатурі):
   - Якщо відповідь **правильна**, з’явиться зелене повідомлення *«Чудово! Відповідь правильна!»*, картка теми у каталозі отримає позначку **«✓ Опрацьовано»**, а до вашого рахунку в шапці додасться **+10 балів**!
   - Якщо у відповіді є **типова помилка** (наприклад, ви написали команду `print(...)` замість самого значення або взяли число в лапки), тренажер пояснить, у чому саме полягає неточність, щоб ви могли легко її виправити.

## 4. Як зберігається ваш прогрес та відповіді на часті запитання (FAQ)
- **Чи зникнуть мої бали, якщо я випадково закрию вкладку або оновлю сторінку (`F5`)?**
  Ні! Тренажер автоматично зберігає всі пройдені теми й набрані бали у внутрішній пам’яті вашого браузера (`localStorage`). При наступному відкритті сайту на цьому ж комп’ютері ваш результат відновиться.
- **Що робити, якщо за шкільним комп’ютером починає працювати інший учень?**
  Натисніть кнопку **«↺ Скинути»** поруч із лічильником балів у верхньому правому куті екрана – тренажер миттєво обнулить прогрес для нового учня.
- **Чи працює тренажер, якщо в комп’ютерному класі тимчасово зник Інтернет?**
  Якщо сторінка тренажера вже була відкрита у браузері, усі уроки, перевірка завдань і блок порад продовжать працювати в автономному режимі завдяки вбудованому резервному сховищу даних (*Fallback*).

## 5. Методичні рекомендації для вчителя інформатики
Вебтренажер «PythonStart» рекомендовано використовувати на уроках інформатики у 8–9 класах під час вивчення розділу **«Алгоритми та програми (мова Python)»**:
1. **Етап актуалізації опорних знань (5–7 хв на початку уроку):** запропонуйте учням пройти 1–2 попередні теми та продемонструвати бейдж `Опрацьовано` на екрані.
2. **Етап закріплення нового матеріалу (10–15 хв):** після пояснення теми (наприклад, циклу `for` або списків `list`) учні самостійно читають короткий конспект у тренажері, розбирають типові помилки за допомогою вбудованого діагноста і набирають 40 з 40 балів.
3. **Домашнє самостійне тренування:** надішліть публічне посилання на GitHub Pages у шкільний чат або електронний щоденник – учні зможуть потренуватися навіть зі смартфона без встановлення Python вдома.
