# Специфікація вимог та межі MVP навчального тренажера «PythonStart»

## 1. Опис освітньої проблеми (Problem Statement)
- **Проблема:** Учні 8–9 класів ЗЗСО та студенти-першокурсники відчувають труднощі під час самостійного опанування базового синтаксису мови програмування Python через складність термінології та відсутність миттєвого зворотного зв’язку під час розв’язання вправ.
- **Потреба користувачів:** Мати доступний україномовний вебтренажер із короткими теоретичними довідками, практичними вправами та зрозумілим поясненням помилок.
- **Рішення:** Розробка інтерактивного клієнтського вебзастосунку «PythonStart».


## 2. Цільова аудиторія (Користувацькі персони)
1. **Основний користувач (Учень / Студент-початківець):** вивчає основи Python («Змінні», «Типи даних», «Умови», «Цикли»), потребує простих пояснень, наочних прикладів коду та миттєвої перевірки відповідей без страху отримати погану оцінку.
2. **Додатковий користувач (Учитель інформатики ЗЗСО):** використовує тренажер на уроках інформатики для закріплення матеріалу та швидкої практичної самоперевірки учнів.

## 3. Користувацькі історії (User Stories) та Критерії прийнятності (Acceptance Criteria)

### US-01. Каталог навчальних тем
- **Історія:** Як учень 8–9 класу, я хочу бачити на головній сторінці впорядкований каталог базових тем з Python, щоб швидко обрати потрібний розділ для навчання.
- **Пріоритет MoSCoW:** Must have (MVP v1.0)
- **Критерії прийнятності:**
  - [ ] На головній сторінці відображається список щонайменше з 4 базових тем Python («Змінні», «Типи даних», «Умовні оператори», «Цикли»).
  - [ ] Кожна картка теми містить заголовок, короткий опис (1–2 речення) та кнопку «Перейти до теми».
  - [ ] При натисканні на кнопку теми відкривається відповідний розділ із теорією та вправами.

### US-02. Теоретична довідка з прикладами коду
- **Історія:** Як учень, я хочу читати коротке теоретичне пояснення з прикладами коду перед початком вправи, щоб пригадати синтаксис мови Python.
- **Пріоритет MoSCoW:** Must have (MVP v1.0)
- **Критерії прийнятності:**
  - [ ] Сторінка обраної теми містить стислий теоретичний блок українською мовою.
  - [ ] У теорії наведено щонайменше один відформатований приклад коду на Python з поясненням результату його роботи.
  - [ ] Під теоретичним блоком розташована помітна кнопка «Почати тренування» (перехід до вправ).

### US-03. Проходження інтерактивної вправи
- **Історія:** Як учень, я хочу виконувати інтерактивні вправи з Python (обирати варіант або вводити фрагмент коду), щоб закріпити вивчений матеріал на практиці.
- **Пріоритет MoSCoW:** Must have (MVP v1.0)
- **Критерії прийнятності:**
  - [ ] Користувач бачить чітке формулювання запитання та фрагмент коду завдання.
  - [ ] Інтерфейс надає варіанти вибору або поле для введення відповіді та кнопку «Перевірити».
  - [ ] Якщо поле відповіді порожнє, при натисканні «Перевірити» виводиться підказка «Спочатку оберіть або введіть відповідь» без зарахування помилки.

### US-04. Миттєва перевірка відповіді та зворотний зв'язок
- **Історія:** Як учень, я хочу отримувати миттєвий результат перевірки своєї відповіді разом із поясненням, щоб розуміти, чи правильно я розв’язав завдання, і вчитися на своїх помилках.
- **Пріоритет MoSCoW:** Must have / Should have (MVP v1.0)
- **Критерії прийнятності:**
  - [ ] Після натискання кнопки «Перевірити» система миттєво аналізує відповідь без перезавантаження вебсторінки.
  - [ ] При текстовому введенні ігноруються випадкові пробіли на початку та в кінці рядка.
  - [ ] Для правильної відповіді виводиться зелене схвальне повідомлення та додається 1 бал до рахунку.
  - [ ] Для неправильної відповіді виводиться повідомлення про помилку та коротке навчальне пояснення правильного варіанту.

### US-05. Підсумковий результат проходження теми
- **Історія:** Як учень, я хочу бачити підсумковий результат (кількість правильних відповідей із загальної кількості) після завершення вправ теми, щоб оцінити свій прогрес.
- **Пріоритет MoSCoW:** Should have (MVP v1.0)
- **Критерії прийнятності:**
  - [ ] Після останнього запитання теми виводиться підсумковий екран із результатом (наприклад, «Ви набрали 4 з 5 балів (80%)»).
  - [ ] На екрані результату є кнопки «Пройти вправу ще раз» та «Повернутися до каталогу тем».

### US-06. Інструкція для учня та вчителя інформатики
- **Історія:** Як учитель інформатики, я хочу мати коротку інструкцію з використання тренажера, щоб швидко організувати роботу класу на уроці.
- **Пріоритет MoSCoW:** Should have (MVP v1.0)
- **Критерії прийнятності:**
  - [ ] Доступний опис сценарію роботи з тренажером для учня та вчителя.
  - [ ] Інтерфейс тренажера коректно відображається як на екрані шкільного комп'ютера, так і на екрані смартфона.

## 5. Межі мінімально життєздатного продукту (MVP v1.0) та план його перевірки
- **Що входить до MVP v1.0:** Каталог із 4 базових тем Python, теоретичні довідки з прикладами, інтерактивні вправи з автоматичною перевіркою, виведення пояснень до помилок та підрахунок балів за тему (історії **US-01 – US-06**).
- **Що НЕ входить до MVP v1.0:** Реєстрація користувачів, особисті кабінети, серверна база даних, ШІ-репетитор.
- **Гіпотеза та спосіб перевірки корисності MVP:** Ми припускаємо, що учні 8–9 класів зможуть самостійно обрати тему в тренажері «PythonStart», ознайомитися з теорією, виконати 3–5 вправ і зрозуміти свої помилки завдяки миттєвим поясненням без додаткових підказок учителя. Перевірка здійснюється шляхом тестування прототипу та MVP на фокус-групі здобувачів.
