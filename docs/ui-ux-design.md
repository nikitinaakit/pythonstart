## 2. Інформаційна архітектура (Карта сайту — Sitemap)
Проєкт MVP v1.0 складається з таких основних екранів:
1. **Головна сторінка / Каталог тем (Desktop 1280x800 та Mobile 375x812)** — вибір теми навчання (відповідає US-01).
2. **Сторінка навчальної теми та вправи** — теоретична довідка з прикладом коду та інтерактивне поле перевірки відповіді (відповідає US-02, US-03).
   - *Стан 2А (Успіх):* зелене повідомлення про правильне розв'язання (US-04).
   - *Стан 2Б (Помилка):* червоне підсвічування та навчальна підказка без стирання введеної відповіді (US-04).
3. **Сторінка підсумкового результату** — відображення набраних балів та навігація назад до каталогу (відповідає US-05).


## 3. Сценарій руху користувача (User Flow)
`Головна (Каталог тем)` ➔ `Вибір теми` ➔ `Ознайомлення з теорією` ➔ `Введення відповіді у вправі` ➔ `Натискання «Перевірити»` ➔ *(якщо помилка: показ підказки і повторна спроба; якщо правильно: перехід далі)* ➔ `Екран результату` ➔ `Повернення до каталогу`.


## 4. Базова дизайн-система та вимоги доступності (Accessibility)
- **Кольорова палітра:** основний фон `#F8FAFC`, фон карток `#FFFFFF`, основний текст `#1E293B`, акцентні кнопки `#2563EB`, колір успіху `#166534` (фон `#DCFCE7`), колір помилки `#991B1B` (фон `#FEE2E2`).
- **Типографіка:** основний шрифт `Inter` / `Roboto` (заголовки `28px`/`20px Bold`, основний текст `16px Regular`), шрифт коду `JetBrains Mono`.
- **Доступність та адаптивність:** забезпечено високий контраст тексту, видимі стани помилок із текстовими поясненнями, перебудову сітки з 3 колонок (ПК) в 1 колонку (смартфон).
