# Методичний паспорт шкільного навчального проєкту
**«Створення та використання інтерактивного вебтренажера "PythonStart" у шкільному курсі інформатики»**

---

## Розділ 1. Загальна інформація про навчальний проєкт
- **Назва шкільного проєкту:** «PythonStart: створюємо власний інтерактивний вебдовідник і тренажер з основ Python»
- **Освітня галузь та предмет:** Інформатична освітня галузь, навчальний предмет «Інформатика»
- **Цільовий клас ЗЗСО:** 9 клас (базовий рівень; можлива адаптація для 8 класу у спрощеному форматі або для 10–11 класів на профільному рівні)
- **Орієнтовна тривалість:** 6 навчальних занять (уроків по 45 хвилин) у межах модуля «Вебтехнології / Алгоритми та програми. Командний проєкт»
- **Формат організації роботи:** малі учнівські команди по 3–4 особи з розподілом ролей та підсумковим шкільним міні-Demo Day

---

## Розділ 2. Навчальна проблема та дидактична мета проєкту
- **Навчальна проблема для учнів:** під час підготовки до контрольних робіт із програмування мовою Python дев’ятикласникам не вистачає зручного інтерактивного тренажера українською мовою, де можна швидко повторити правила за допомогою коротких карток і перевірити себе на типових тестових прикладах.
- **Дидактична мета:** сформувати в учнів практичні навички командної розробки простого освітнього вебпродукту (від задуму і макета до публікації й тестування), закріпивши водночас знання базових конструкцій мови Python (змінні, умови, цикли, списки) та основ вебтехнологій (HTML5, CSS3, базовий JavaScript).

---

## Розділ 3. Очікувані результати навчання учнів (Компетентнісний підхід)
1. **Предметні результати (Інформатика та програмування):**
   - учень/учениця розуміє призначення семантичної розмітки HTML5, стилів CSS3 та сценаріїв JavaScript у роботі вебсторінки;
   - уміє структурувати навчальні завдання з мови Python (формулювати теоретичну довідку, приклад коду, правильну відповідь та пояснення типової помилки);
   - застосовує базовий алгоритм перевірки введених даних і тестує програму на крайових випадках (порожнє введення, зайві пробіли, регістр літер).
2. **Цифрові компетентності:**
   - безпечно працює у спільному середовищі розробки (VS Code / браузерний редактор та GitHub на базовому рівні);
   - використовує інструменти перегляду коду сторінки у браузері та дотримується правил цифрової доступності (контрастність, зрозумілі підписи кнопок).
3. **Наскрізні вміння та м’які навички (Soft Skills):**
   - домовляється про розподіл обов’язків у малій групі (3–4 учні) і дотримується спільних строків;
   - конструктивно перевіряє роботу однокласника за чеклістом і аргументовано презентує спільний результат під час 4-хвилинного шкільного пітчу.

## Розділ 4. Цільова група учнів, стартова підготовка та диференціація
- **Вік учнів:** 14–15 років (9 клас).
- **Необхідні попередні знання:** базове знайомство зі структурою HTML-документа (`<div>`, `<h2>`, `<button>`, `<input>`), елементарними властивостями CSS (колір, відступи, шрифт) та початковими поняттями мови Python (команда `print()`, змінні, умовний оператор `if`).
- **Диференціація за рівнем підготовки (Матриця масштабування 7–11 класи):**
  - *Для 7–8 класів (або учнів початкового рівня):* учні отримують повністю готовий шаблон тренажера «PythonStart» і працюють лише з файлом даних `data/topics.js` та кольоровою палітрою в `css/base.css` (додають власні навчальні картки й питання без редагування складної логіки JS).
  - *Для 9 класу (основний сценарій):* учні створюють макет картки, верстають HTML/CSS-блоки, наповнюють базу тем Python і налаштовують функцію перевірки відповіді за шаблоном учителя.
  - *Для 10–11 класів (профільний рівень):* учні самостійно працюють у гілках GitHub, пишуть логіку фільтрації та збереження у `localStorage`, проводять взаємне Code Review та публікують сайт на GitHub Pages.

## Розділ 6. Інструменти, ресурси, педагогічні опори (Scaffolding) та робота в автономному режимі
- **Програмне забезпечення (100 % безкоштовне):** браузер (Chrome / Firefox / Edge), редактор коду Visual Studio Code із розширенням Live Server, редактор Penpot (або паперовий шаблон для макетування), еталонний репозиторій «PythonStart».
- **Комплект педагогічних опор учителя (Scaffolding):**
  1. Стартовий архів проєкту (`pythonstart-school-starter.zip`) із готовою модульною структушою та коментарями-підказками `// ЗАВДАННЯ ДЛЯ УЧНЯ:` у коді.
  2. Друковані картки ролей у команді з чітким переліком обов’язків на кожен урок.
  3. Чекліст взаємного тестування з 5 пунктів для учня-тестувальника.
- **План безперервності навчання за відсутності Інтернету або під час роботи в укритті:** усі матеріали проєкту (стартовий шаблон, інструкція `docs/user-guide.md`, локальна база порад `data/daily-tips.json`) попередньо скопійовані на шкільні комп’ютери або ноутбуки й працюють повністю локально без підключення до мережі Інтернет.

## Розділ 7. Система оцінювання учнівського проєкту (Продукт + Процес + Рефлексія)
Оцінювання здійснюється за 12-бальною шкалою ЗЗСО і складається з трьох збалансованих компонентів (детальна рубрика подана у файлі `docs/school-rubrics-and-scaffolding.md`):
1. **Якість створеного продукту (до 5 балів):** працездатність вебтренажера, правильність завдань з Python, охайність інтерфейсу, адаптивність і відсутність помилок при перевірці відповіді.
2. **Процес командної взаємодії та особистий внесок (до 4 балів):** виконання своєї ролі у команді, дотримання етапів планування, взаємна допомога та перевірка роботи за чеклістом.
3. **Публічний захист на шкільному Demo Day та індивідуальна рефлексія (до 3 балів):** здатність учня пояснити свою частину роботи за 1 хвилину, відповісти на запитання вчителя та сформулювати висновок під час ретроспективи.

## Розділ 8. Цифрова безпека, академічна доброчесність та етичне використання ШІ у школі
- **Захист персональних даних учнів:** у відкритих репозиторіях, на сторінках сайту та у файлі `README.md` заборонено публікувати домашні адреси, номери телефонів, особисті фотографії чи паролі учнів (використовуються лише імена або шкільні псевдоніми).
- **Правила використання штучного інтелекту (ШІ) учнями:** учням дозволяється звертатися до ШІ для пояснення незрозумілих понять або пошуку ідей прикладів коду Python, але **категорично заборонено** сліпо копіювати згенерований код без розуміння. Кожен учень на захисті повинен уміти усно пояснити будь-який рядок свого коду чи завдання.
- **Авторське право та доброчесність:** усі текстові матеріали та іконки у проєкті є власними розробками команди або походять із відкритих освітніх джерел з вільною ліцензією (MIT / Creative Commons).

## Розділ 9. Формат проведення шкільного Demo Day та учнівської ретроспективи
- **Регламент виступу шкільної команди (4 хвилини):**
  - *1 хвилина:* назва команди, які теми з Python обрали і чому вони важливі.
  - *2 хвилини:* демонстрація роботи сайту на проекторі (один учень керує браузером, інший коментує перевірку правильної та помилкової відповіді).
  - *1 хвилина:* відповідь на 1–2 запитання класу та вчителя.
- **Учнівська експрес-ретроспектива «Три смайлики»:** після виступів кожна команда за 3 хвилини заповнює коротку картку: 1) *Що нам вдалося найкраще?* | 2) *Що було найскладнішим?* | 3) *Чого ми навчилися одне в одного?*
