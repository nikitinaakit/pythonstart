| Складник оцінювання | Початковий рівень (1–3 бали сумарно) | Середній рівень (4–6 балів сумарно) | Достатній рівень (7–9 балів сумарно) | Високий рівень (10–12 балів сумарно) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Якість програмного продукту** *(макс. 5 балів)* | Сторінка відкривається з помилками, містить лише фрагмент тексту за шаблоном; перевірка відповіді не працює (1 бал). | Сторінка відображається коректно, додано 1–2 теми Python за шаблоном, але є неточності у стилях або перевірці відповідей (2–3 бали). | Тренажер працює стабільно, додано 3 змістовні теми з Python, коректно спрацьовує перевірка правильної та хибної відповіді (4 бали). | Повністю працюючий, адаптивний і охайний тренажер; реалізовано підказки для типових помилок, пошук і збереження балів без жодного дефекту (5 балів). |
| **2. Командний процес та індивідуальний внесок** *(макс. 4 бали)* | Учень пасивно спостерігав за роботою групи, виконав мінімальну дію лише за прямою вказівкою вчителя (1 бал). | Учень виконав частину свого завдання за карткою ролі, але потребував постійної допомоги та не брав участі у взаємній перевірці (2 бали). | Учень відповідально виконав свою роль (дизайн, контент, код або тестування), дотримувався плану та допоміг команді інтегрувати файли (3 бали). | Учень проявив ініціативу, якісно виконав свою роль, провів перевірку роботи колег за чеклістом і допоміг усунути помилки (4 бали). |

Презентація на Demo Day та рефлексія** *(макс. 3 бали)* | Читає чужий текст із аркуша, не може пояснити, як працює його частина проєкту (1 бал). | Коротко називає тему проєкту, але плутається при демонстрації та відповідях на прості запитання вчителя (1,5–2 бали). | Чітко демонструє свою частину роботи під час пітчу, правильно відповідає на запитання щодо свого модуля (2,5 бала). | Переконливо і грамотно виступає в регламенті пітчу, пояснює логіку коду та формулює зрілі висновки під час ретроспективи (3 бали). |

## 2. Картка педагогічної підтримки № 1 (Scaffolding): Шаблон для додавання нової теми Python учнями 8–9 класів

*Інструкція для вчителя:* роздайте цей шаблон учням, які відповідають за наповнення бази знань у файлі `data/topics.js`. Учням достаньо замінити текст у лапках після коментарів `// ЗАПОВНІТЬ ТУТ:`, не боячись зламати синтаксис JavaScript.

```javascript
// КАРТКА-ШАБЛОН ДЛЯ УЧНЯ (скопіюйте у файл data/topics.js)
{
  // ЗАПОВНІТЬ ТУТ: унікальний текстовий ідентифікатор теми латиницею (без пробілів)
  id: 'strings-basics',

  // ЗАПОВНІТЬ ТУТ: порядковий номер і зрозуміла назва теми українською мовою
  title: '5. Рядки (str) та операції над текстом',

  // ЗАПОВНІТЬ ТУТ: рівень складності ('Початковий' або 'Базовий')
  difficulty: 'Початковий',

  // ЗАПОВНІТЬ ТУТ: коротке пояснення правила (2-3 речення для однокласників)
  theory: 'Рядок (string) у Python – це послідовність символів, взята в одинарні або подвійні лапки. Функція len() дозволяє дізнатися кількість символів у рядку.',

  // ЗАПОВНІТЬ ТУТ: наочний приклад коду Python
  codeExample: 'word = "Python"\nprint(len(word))',

  // ЗАПОВНІТЬ ТУТ: запитання практичної вправи для перевірки
  question: 'Що виведе на екран програма: word = "Код"; print(len(word)) ?',

  // ЗАПОВНІТЬ ТУТ: точна правильна відповідь (лише значення без лапок)
  expectedAnswer: '3',

  // ЗАПОВНІТЬ ТУТ: дружня підказка, якщо однокласник натисне кнопку «Показати підказку»
  hint: 'Порахуйте кількість літер у слові "Код". Функція len() повертає ціле число.'
}
```

## 3. Картка педагогічної підтримки № 2 (Scaffolding): Чекліст учня-тестувальника перед шкільним Demo Day

Перед тим як показувати свій проєкт класу на уроці № 6, учень у ролі **Тестувальника (QA)** перевіряє сайт команди за 5 простими кроками:

- [ ] **Перевірка 1 (Зовнішній вигляд):** Усі назви тем, кнопки та підказки написані грамотною українською мовою, текст добре читається на фоні карток.
- [ ] **Перевірка 2 (Порожнє поле):** Якщо натиснути «Перевірити відповідь», нічого не ввівши у поле, програма не ламається, а ввічливо просить ввести відповідь.
- [ ] **Перевірка 3 (Нечутливість до пробілів):** Якщо перед правильною відповіддю випадково поставити пробіл (наприклад, `  15 `), тренажер все одно зараховує її як правильну.
- [ ] **Перевірка 4 (Підказка):** Натискання кнопки «Показати підказку» відкриває корисне пояснення, яке допомагає розв’язати завдання.
- [ ] **Перевірка 5 (Смартфон):** При звуженні вікна браузера картки тем не налазять одна на одну, а кнопки залишаються зручними для натискання.
