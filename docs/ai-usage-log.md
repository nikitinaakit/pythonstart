# Журнал використання штучного інтелекту (AI Usage Log) – Проєкт «PythonStart»

## 1. Регламент відповідального використання ШІ в команді
1. **Призначення ШІ:** Генеративні моделі (Google Gemini, ChatGPT, Copilot) використовуються виключно як допоміжний інструмент для генерації чернеток коду, пошуку граничних випадків (Edge Cases), рефакторингу та створення навчальних прикладів.
2. **Обов’язкова верифікація людиною:** Жоден рядок згенерованого ШІ коду не додається у гілку `main` без ручної перевірки синтаксису, відповідності модульній архітектурі (`data/`, `js/`, `css/`), захисту від XSS-вразливостей (`textContent` замість `innerHTML`) та тестування у браузері.
3. **Академічна доброчесність:** Кожен автор коміту несе 100% персональної відповідальності за код у своєму Pull Request і зобов’язаний вміти пояснити логіку кожної функції під час Code Review та захисту.
