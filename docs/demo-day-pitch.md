## 3. План технічної безпеки та резервної демонстрації (Fallback Plan «Б»)

На випадок технічних збоїв у мережі під час публічного захисту команда підготувала трирівневий резерв:
1. **Рівень 1 (Попередньо завантажена вкладка Production):** за 10 хвилин до початку Demo Day сторінка `https://ЛОГІН_КООРДИНАТОРА.github.io/pythonstart/` відкривається у браузері доповідача (усі JS/CSS модулі вже закешовані у пам’яті браузера).
2. **Рівень 2 (Автономний локальний сервер Live Server):** на ноутбуці доповідача запущено локальну копію гілки `main` за адресою `http://127.0.0.1:5500/index.html`. Завдяки реалізованому у ЛР № 9 механізму *Fallback* тренажер автоматично перемикається на локальний файл `data/daily-tips.json` за повної відсутності Інтернету.
3. **Рівень 3 (Резервні слайди зі скриншотами станів):** у кінець презентації (Слайди 7–9, приховані/резервні) додано повнорозмірні знімки екрана всіх 4 сценаріїв демонстрації та зеленого логу GitHub Actions.

## 4. Підготовлені відповіді команди на типові запитання експертів (FAQ для Q&A)

- **Запитання 1:** *Чому для збереження балів учня обрано `localStorage`, а не серверну базу даних із реєстрацією?*
  - **Відповідь:** Це свідоме архітектурне рішення в межах MVP v1.0 для школи: учням 8–9 класів не потрібно створювати облікові записи чи вводити персональні дані (відповідність нормам цифрової безпеки неповнолітніх), а сайт працює миттєво і безкоштовно на GitHub Pages.
- **Запитання 2:** *Яку функцію було найскладніше реалізувати та протестувати?*
  - **Відповідь:** Модуль інтелектуальної діагностики типових помилок учня (`diagnoseStudentMistake` у `js/validation.js`), де потрібно було відокремити синтаксичні помилки (зайві лапки, `print()`, регістр) від неправильної відповіді та покрити всі крайові випадки модульними тестами Vitest.
- **Запитання 3:** *Як учитель може перевірити, що за шкільним комп’ютером бали набрав саме поточний учень, а не попередній клас?*
  - **Відповідь:** У шапці тренажера реалізовано кнопку швидкого скидання прогресу `«↺ Скинути»` (`#reset-progress-btn`), яку учень натискає на початку уроку перед виконанням вправ.
