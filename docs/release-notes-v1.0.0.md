# Паспорт релізу v1.0.0 та протокол димового тестування (Smoke Testing)

## 1. Короткий опис релізу для публікації у GitHub Releases
**Навчальний вебтренажер «PythonStart» v1.0.0 (MVP Release)** – перший стабільний публічний випуск інтерактивного клієнтського вебзастосунку для підтримки вивчення основ програмування мовою Python у 8–9 класах ЗЗСО. Усі заплановані функції мінімально життєздатного продукту (MVP) реалізовані, протестовані (понад 30 модульних тестів Vitest у 4 тестових наборах + статичний аналізатор коду) та розгорнуті у відкритому доступі на сервісі GitHub Pages.

## 3. Протокол післярелізного димового тестування (Production Smoke Test Checklist)
Цей чекліст виконується командою відразу після публікації сайту за публічною адресою `https://nikitinaakit.github.io/pythonstart/`:

- [x] **ST-01 (Доступність та HTTPS):** Сайт відкривається за публічним посиланням GitHub Pages зі статусом `200 OK` через захищене з’єднання `https://`.
- [x] **ST-02 (Цілісність ресурсів у DevTools):** У вкладках *Console* та *Network* браузера (F12) відсутні помилки `404 Not Found` для файлів `css/styles.css`, `js/app.js` та `data/daily-tips.json`.
- [x] **ST-03 (Рендеринг каталогу та пошук):** У лівій панелі коректно відображаються всі 4 теми; введення слова «списки» миттєво фільтрує картки.
- [x] **ST-04 (Валідація та діагностика помилок):** У темі 1 введення `print(15)` виводить інтелектуальне попередження, а введення `15` зараховує тему та додає `+10 балів`.
- [x] **ST-05 (Збереження стану в Production):** Після натискання `F5` на опублікованому сайті статус «✓ Опрацьовано» та набрані бали зберігаються у `localStorage` домену `github.io`.
- [x] **ST-06 (Робота віджета API та мобільна адаптивність):** Віджет «Порада дня» завантажує поради, а при зменшенні ширини екрана до 375 px (смартфон) інтерфейс перебудовується в одну колонку без горизонтальної прокрутки.
