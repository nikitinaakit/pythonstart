## 1. Загальна інформація про проєкт
Програмний продукт розробляється в межах вивчення освітнього компонента «Командна розробка програмних проєктів».

## 3. Опис проблеми та цільова аудиторія
- **Освітня проблема:** Складність первинного опанування текстового коду здобувачами без попереднього досвіду програмування.
- **Портрет цільової аудиторії:** Учні 8–11 класів закладів загальної середньої освіти (ЗЗСО), студенти перших курсів спеціальності 014.09 «Середня освіта (Інформатика)», вчителі інформатики.
- **Формулювання проблеми (Problem Statement):** Учні старших класів та студенти-першокурсники відчувають високий бар’єр входження у програмування через складність абстрактної термінології та відсутність інтерактивних україномовних тренажерів базового рівня, що призводить до зниження мотивації при написанні перших програм.
## 4. Мета проєкту та межі першої версії (МЖП / MVP)
- **Мета:** Створити інтерактивний навчальний тренажер «PythonStart» для закріплення тем «Змінні», «Умови» та «Цикли».
- **Увійде до першої версії – мінімально життєздатного продукту (МЖП / англ. MVP – Minimum Viable Product):** каталог базових тем, короткі теоретичні довідки, інтерактивні тестові вправи з миттєвою перевіркою відповіді.
- **Не входить до першої версії (відкладено на майбутнє):** складна реєстрація користувачів, серверна база даних, інтеграція зі шкільним електронним журналом.
## 5. Правила взаємодії команди

2. Усі домовленості та розподіл завдань фіксуються письмово.

## 7. Організація командної роботи

- **Проєкт:** Навчальний тренажер «PythonStart»
- **Інструмент керування завданнями:** GitHub Issues та GitHub Projects.
- **Посилання на Kanban-дошку:** [PythonStart – Team Board](https://github.com/users/nikitinaakit/projects/2/views/1)
- **Посилання на контрольний етап:** [Milestone MVP v1.0](https://github.com/nikitinaakit/pythonstart/milestone/1)

### Kanban-статуси дошки:
- **Backlog** – усі заплановані роботи та ідеї;
- **To do** – відібрані завдання для найближчого виконання;
- **In progress** – завдання, що перебувають у роботі просто зараз;
- **Review** – перевірка отриманого результату іншим учасником команди;
- **Done** – критерії прийнятності повністю виконані та перевірені.

### Правила команди:
1. Кожне завдання (Issue) має чіткий опис, критерії прийнятності та одного відповідального виконавця (Assignee).
2. Для всіх завдань визначаються тип роботи і пріоритет за допомогою міток (Labels).
3. Завдання першої версії продукту об’єднуються контрольним етапом **Milestone MVP v1.0**.
4. Перед переходом у статус `Done` результат обов’язково перевіряє інший член команди на етапі `Review`.
5. Зміни статусів на дошці мають відповідати фактичному стану виконання роботи.

# Навчальний вебтренажер «PythonStart» (Реліз v1.0.0)

![CI Status](https://github.com/nikitinaakit//pythonstart/actions/workflows/ci.yml/badge.svg)

Інтерактивний клієнтський вебзастосунок для вивчення базових конструкцій мови програмування Python учнями 8–9 класів закладів загальної середньої освіти (ЗЗСО).

## Публічне посилання на розгорнутий застосунок (Production)
- **Працюючий сайт на GitHub Pages:** [https://nikitinaakit/.github.io/pythonstart/](https://nikitinaakit/.github.io/pythonstart/)
- **Репозиторій вихідного коду:** [https://github.com/nikitinaakit//pythonstart](https://github.com/nikitinaakit//pythonstart)
- **Командна Kanban-дошка (GitHub Projects):** PythonStart – Team Board
- **Офіційний випуск (Release):** `v1.0.0 (MVP)`

## Освітня проблема та цільова аудиторія
- **Проблема:** Учні 8–9 класів під час переходу до текстового програмування мовою Python часто припускаються синтаксичних помилок (забувають двокрапку в умовах і циклах, плутають регістр або лапки) і втрачають мотивацію через складні повідомлення англомовних компіляторів.
- **Цільова аудиторія:** Учні 8–9 класів на уроках інформатики та під час самостійної підготовки вдома, а також вчителі інформатики, яким потрібен швидкий інструмент формувального оцінювання без встановлення додаткового ПЗ.

## Основні можливості релізу MVP v1.0.0 та відомі обмеження
**Реалізовано у версії v1.0.0:**
1. **Каталог із 4 базових тем Python:** «Змінні та типи даних», «Умовний оператор if», «Цикл for та функція range()», «Списки (list) та індексація».
2. **Миттєвий пошук і фільтрація:** живий пошук за назвою чи описом теми та фільтрація за статусом («Усі», «Опрацьовані», «Неопрацьовані»).
3. **Інтерактивне робоче поле та інтелектуальна діагностика помилок:** перевірка введеної відповіді з нечутливістю до регістру та зайвих пробілів, санітизацією від XSS та розпізнаванням типових учнівських помилок (`print(...)`, зайві лапки, крапка з комою) із дружнім поясненням українською мовою.
4. **Автоматичне збереження прогресу (`localStorage`):** збереження пройдених тем і набраних балів у браузері учня з можливістю безпечного скидання результату кнопкою «↺ Скинути».
5. **Інтеграція із зовнішнім REST API та механізм Fallback:** блок «Порада дня з Python» і жива статистика репозиторію з GitHub API, які автоматично переходять на резервні локальні дані за відсутності Інтернету.

**Відомі обмеження поточної версії (відкладено на v2.0):**
- Відсутня серверна база даних і централізований кабінет вчителя (прогрес зберігається локально в браузері конкретного пристрою).
- Перевіряються короткі фрагменти коду та результати виконання без запуску повноцінного серверного інтерпретатора Python.

## Технологічний стек та інженерні інструменти
- **Клієнтська частина (Frontend):** Семантичний HTML5, модульний CSS3 (CSS Variables, Flexbox, CSS Grid, адаптивна верстка), чистий JavaScript (ES6+ Modules, DOM API, Fetch API, Web Storage API).
- **Контроль якості та CI/CD:** Середовище Node.js, фреймворк модульного тестування Vitest (понад 30 модульних тестів у 4 тестових наборах), власний статичний аналізатор коду (`scripts/lint-check.js`), конвеєр GitHub Actions (`.github/workflows/ci.yml`).
- **Проєктування та управління:** Penpot (UI/UX прототип), GitHub Issues, Milestones, GitHub Projects (Kanban), GitHub Pages.

## Інструкція локального запуску та перевірки якості
1. Клонуйте репозиторій на свій комп’ютер та перейдіть у папку проєкту:
   ```bash
   git clone https://github.com/nikitinaakit//pythonstart.git
   cd pythonstart
   ```
2. Встановіть залежності для тестування (потрібен встановлений Node.js версії 18+ або 20+):
   ```bash
   npm install
   ```
3. Запустіть повну перевірку якості коду (статичний лінтер + модульні тести Vitest):
   ```bash
   npm run lint
   npm test
   npm run ci:check
   ```
4. Для відкриття вебінтерфейсу у браузері відкрийте папку в редакторі VS Code і натисніть кнопку **Go Live** (розширення *Live Server*) на файлі `index.html`. Детальний опис конвеєра CI/CD наведено у файлі [docs/ci-cd-pipeline.md](./docs/ci-cd-pipeline.md).
