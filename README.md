# Навчальний тренажер «PythonStart»
## 1. Загальна інформація про проєкт
Програмний продукт розробляється в межах вивчення освітнього компонента «Командна розробка програмних проєктів».
Тренажер призначений для первинного засвоєння базових понять програмування мовою Python.

## 3. Опис проблеми та цільова аудиторія
- **Освітня проблема:** Складність первинного опанування текстового коду здобувачами без попереднього досвіду програмування.
- **Портрет цільової аудиторії:** Учні 8–11 класів закладів загальної середньої освіти (ЗЗСО), студенти перших курсів спеціальності 014.09 «Середня освіта (Інформатика)», вчителі інформатики.
- **Формулювання проблеми (Problem Statement):** Учні старших класів та студенти-першокурсники відчувають високий бар’єр входження у програмування через складність абстрактної термінології та відсутність інтерактивних україномовних тренажерів базового рівня, що призводить до зниження мотивації при написанні перших програм.
## 4. Мета проєкту та межі першої версії (МЖП / MVP)
- **Мета:** Створити інтерактивний навчальний тренажер «PythonStart» для закріплення тем «Змінні», «Умови» та «Цикли».
- **Увійде до першої версії – мінімально життєздатного продукту (МЖП / англ. MVP – Minimum Viable Product):** каталог базових тем, короткі теоретичні довідки, інтерактивні тестові вправи з миттєвою перевіркою відповіді.
- **Не входить до першої версії (відкладено на майбутнє):** складна реєстрація користувачів, серверна база даних, інтеграція зі шкільним електронним журналом.
## 5. Правила взаємодії команди
1. Основне місце спілкування – спільний чат команди та репозиторій GitHub.
2. Усі домовленості та розподіл завдань фіксуються письмово.
## 6. Структура проєкту та інструкція із запуску
Проєкт має модульну структуру:
- `src/main.py` – головний файл запуску тренажера;
- `src/math_quiz.py` – інтерактивний модуль вікторини;
- `docs/` – методичні матеріали та документація проєкту.
## 7. Організація командної роботи

- **Проєкт:** Навчальний тренажер «PythonStart»
- **Інструмент керування завданнями:** GitHub Issues та GitHub Projects.
- **Посилання на Kanban-дошку:** [PythonStart – Team Board]https://github.com/users/nikitinaakit/projects/2
- **Посилання на контрольний етап:** [Milestone MVP v1.0]https://github.com/nikitinaakit/pythonstart/milestone/1

### Kanban-статуси дошки:
- **Backlog** – усі заплановані роботи та ідеї;
- **To do** – відібрані завдання для найближчого виконання;
- **In progress** – завдання, що перебувають у роботі просто зараз;
- **Review** – перевірка отриманого результату іншим учасником команди;
- **Done** – критерії прийнятності повністю виконані та перевірені.

### Правила команди:
1. Кожне завдання (Issue) має чіткий опис, критерії прийнятності та одного відповідального виконавця (Assignee).
2. Для всіх завдань визначаються тип роботи і пріоритет за допомогою міток (Labels).
3. Завдання першої версії продукту об’єднуються контрольним етапом **Milestone MVP v1.0**.
4. Перед переходом у статус `Done` результат обов’язково перевіряє інший член команди на етапі `Review`.
5. Зміни статусів на дошці мають відповідати фактичному стану виконання роботи.
