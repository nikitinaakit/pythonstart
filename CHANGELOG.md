# Журнал змін проєкту «PythonStart» (Changelog)

Усі суттєві зміни, нові функції та виправлення безпеки навчального тренажера «PythonStart» документуються у цьому файлі відповідно до стандарту [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/) та правил семантичного версіонування [Semantic Versioning (SemVer)](https://semver.org/lang/uk/).

## [1.0.0] – 2026-11-14 (Перший офіційний реліз MVP)

### Додано (Added)
- **Каталог навчальних тем (`data/topics.js`, `js/topics.js`):** 4 структуровані уроки з основ мови Python для 8–9 класів («Змінні та типи даних», «Умовний оператор if», «Цикл for та функція range()», «Списки (list) та індексація»).
- **Пошук та фільтрація:** миттєвий пошук тем за ключовими словами у назві чи описі та фільтрація за статусом проходження («Усі», «Опрацьовані», «Неопрацьовані»).
- **Інтерактивне робоче поле (`js/workspace.js`, `js/validation.js`):** перевірка відповідей учня з нормалізацією рядків та інтелектуальним діагностуванням типових помилок початківців (`diagnoseStudentMistake`).
- **Клієнтське збереження прогресу (`js/storage.js`):** автоматичне збереження виконаних тем і набраних балів у `localStorage` браузера (ключ `pythonstart_progress_v1`) та кнопка безпечного скидання результату «↺ Скинути».
- **Інтеграція REST API із захистом Fallback (`js/api.js`, `js/apiWidget.js`):** асинхронне завантаження «Поради дня з Python» та метаданих репозиторію з GitHub REST API з автоматичним перемиканням на резервні дані за відсутності зв’язку.
- **Українська локалізація (`js/messages.uk.js`, `js/i18n.js`):** централізований словник усіх повідомлень інтерфейсу з резервним захистом через оператор нульового злиття `??`.
- **Автоматизований контроль якості (`tests/`, `.github/workflows/ci.yml`):** понад 30 модульних тестів у 4 тестових наборах на фреймворку Vitest, статичний аналізатор `scripts/lint-check.js` та хмарний конвеєр безперервної інтеграції GitHub Actions.
- **Комплексна документація (`README.md`, `docs/`):** технічний паспорт, посібник користувача для школи (`docs/user-guide.md`), опис конвеєра CI/CD (`docs/ci-cd-pipeline.md`), архітектурна специфікація, контракт даних та журнал взаємодії з ШІ (`docs/ai-usage-log.md`).

### Змінено (Changed)
- **Архітектура застосунку:** виконано повний перехід на ізольовані модулі стандарту ES6 Modules за принципом єдиної відповідальності (SRP).
- **Шляхи до ресурсів:** усі посилання на таблиці стилів, скрипти та JSON-дані уніфіковано як відносні для безпомилкової роботи у підкаталозі сервісу GitHub Pages.

### Виправлено (Fixed)
- **Санітизація та нормалізація відповіді з крапкою з комою (BUG-02):** відповіді учнів із великими літерами, кратними пробілами та необов’язковою крапкою з комою `;` наприкінці тепер розпізнаються коректно.
- **Стійкість пошуку та фільтрації каталогу (BUG-03):** усунено збій при передачі некоректного масиву тем та очищено пошуковий запит від зайвих пробілів.
- **Цілісність даних у `localStorage` та захист від дублювання балів (BUG-04):** повторне введення правильної відповіді у вже пройденій темі більше не збільшує лічильник балів, а пошкоджені поля сховища безпечно відновлюються.

### Безпека (Security)
- **Захист від міжсайтового скриптингу (XSS):** у модулі `js/validation.js` впроваджено функцію `sanitizeInput()`, а у клієнтських модулях та статичному лінтері (`scripts/lint-check.js`) заблоковано небезпечні конструкції на користь безпечного виведення тексту через `textContent`.
- **Ізоляція сховища браузера:** під час скидання прогресу використовується точковий метод `localStorage.removeItem('pythonstart_progress_v1')` замість глобального `localStorage.clear()`.
